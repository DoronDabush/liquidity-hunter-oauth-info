Privacy Policy

Last updated: October 12, 2026

About the Application

Liquidity Hunter Backup is a private, owner-operated utility for backing up database files to Google Drive. It is not a public service.

Google Drive Access

The application uses Google OAuth with the limited drive.file permission. It accesses files created or authorized for use by the application, rather than requesting general access to the user's Drive.

How Information Is Used

Google Drive access is used to upload, verify, retrieve, and manage application backup files.

Database backups are intended to be encrypted before upload to Google Drive.

Data Storage and Security

OAuth credentials are stored in the owner's authorized rclone configuration and, when cloud automation is enabled, in protected automation secrets.

Backup files are stored in the Google Drive account authorized by the owner. Temporary local copies may be used during backup and recovery operations.

Sharing and Advertising

Google user data is not sold or used for advertising. Data is processed only as necessary to provide the owner's requested backup functionality.

Retention and Deletion

Backup files remain in Google Drive until removed by the owner or an explicitly configured retention process. The owner can remove backup files through Google Drive and revoke OAuth access through Google Account security settings.

Changes to This Policy

This page will be updated if the application's data access or processing practices change.
